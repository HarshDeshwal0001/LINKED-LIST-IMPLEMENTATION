##This project implements a basic singly linked list in C to demonstrate fundamental data structure operations. The program supports inserting nodes at the end, deleting a node by value, and displaying the contents of the list. It uses a simple structure with modular functions like insertAtEnd, deleteNode, and printList, making the code easy to understand and maintain. The program uses dynamic memory allocation (malloc) to create nodes and ensures proper memory handling by freeing memory when nodes are deleted. This task was completed using the GCC compiler in a terminal environment and is aimed at building foundational understanding of linked lists in C.
